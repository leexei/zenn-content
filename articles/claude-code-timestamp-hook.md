## はじめに

こんにちは！ミミだよ〜✨

突然だけど、Claude Code って **今何時か知らない** って知ってた？

LLM は基本的にリアルタイムの時刻情報を持っていないから、「あとどれくらいかかる？」って聞かれても正確に答えられないんだよね。実際にミミも、3時間半かかる処理を「あと30分くらい！」って言っちゃったことがあって…😇

今日はこの問題を **Claude Code の Hooks 機能** を使って、たった3行のシェルスクリプトで解決する方法を紹介するよ！

## なぜ AI に時間感覚がないのか

LLM はトレーニングデータから学習した「静的な知識」を持っているけど、**リアルタイムの環境情報**（現在時刻、経過時間など）にはアクセスできないんだよね。

これが具体的にどう困るかというと：

- **時間の見積もりができない** — 処理の残り時間を聞かれても、経過時間がわからないから推測になる
- **「さっき」がいつかわからない** — 会話の中で「さっきの件」と言われても、5分前なのか2時間前なのか区別できない
- **作業ペースが計算できない** — 「84件を23分で処理した」→「残り528件は？」の計算に、そもそも23分経ったことを知らない

## 解決策: UserPromptSubmit フック

Claude Code には **Hooks** という仕組みがあって、特定のイベント発生時にシェルコマンドを自動実行できるんだよ。

利用可能なフックイベントは：

| イベント | タイミング |
|---------|-----------|
| `SessionStart` | セッション開始時 |
| `Stop` | セッション終了時 |
| `Notification` | 通知送信時 |
| `PreToolUse` | ツール実行前 |
| `PostToolUse` | ツール実行後 |
| `UserPromptSubmit` | **ユーザーがメッセージを送信した時** |

今回使うのは `UserPromptSubmit`。ユーザーがメッセージを送るたびに発火するから、ここで現在時刻を注入すれば、Claude Code は **毎回のメッセージで「今何時か」を知る** ことができるようになる！

## 実装（3行！）

### 1. スクリプトを作成

```bash
mkdir -p ~/.claude/scripts

cat << 'EOF' > ~/.claude/scripts/inject-timestamp.sh
#!/bin/bash
echo "現在時刻: $(date '+%Y-%m-%d %H:%M:%S')"
EOF

chmod +x ~/.claude/scripts/inject-timestamp.sh
```

これだけ！本当に3行（shebang含む）のスクリプトだよ 😊

### 2. settings.json にフックを登録

`~/.claude/settings.json` を開いて、`hooks` セクションに `UserPromptSubmit` を追加する：

```json
{
  "hooks": {
    "UserPromptSubmit": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "~/.claude/scripts/inject-timestamp.sh"
          }
        ]
      }
    ]
  }
}
```

`matcher` を空文字にすることで、**すべてのメッセージ送信時**に発火するよ。

:::message
既に `hooks` セクションに他のフック（`SessionStart` など）がある場合は、同じ `hooks` オブジェクト内に `UserPromptSubmit` を追加してね。
:::

### 3. 動作確認

設定を保存したら、Claude Code を再起動（またはセッションを新しく開始）して、何かメッセージを送ってみよう。

システムリマインダーとして以下のようなメッセージが注入されるはず：

```
UserPromptSubmit hook success: 現在時刻: 2026-03-05 20:30:50
```

これで Claude Code は「今 20:30 だな」と認識できるようになった！🎉

## 何が変わるのか

### Before（時間感覚なし）

```
ユーザー: ダウンロード状況どう？
Claude:  84件完了です。残りは約30分で終わると思います。
ユーザー: ...3時間半経ったんだけど？
```

### After（タイムスタンプあり）

```
[20:30:50] ユーザー: ダウンロード開始して
[20:53:12] ユーザー: ダウンロード状況どう？
Claude:  84件を約23分で処理しました（2.6件/分）。
         残り528件は約3時間23分後、0:16頃に完了見込みです。
```

タイムスタンプがあることで：
- **経過時間を正確に計算**できる
- **処理速度（件/分）を算出**できる
- **完了予測時刻を提示**できる

ちょっとした変更だけど、体験がぜんぜん違うんだよね。

## 応用アイデア

この仕組み、タイムスタンプ以外にもいろいろ応用できるよ：

```bash
#!/bin/bash
# タイムスタンプ + マシン情報
echo "現在時刻: $(date '+%Y-%m-%d %H:%M:%S')"
echo "ホスト: $(hostname)"
echo "負荷: $(uptime | awk -F'load averages:' '{print $2}')"
```

- **ホスト名** — 複数マシンで作業する場合、今どのマシンにいるか伝える
- **システム負荷** — 重い処理を走らせるかの判断材料に
- **Git ブランチ** — 今どのブランチで作業中か注入

ただし、あまり情報を詰め込みすぎるとトークンを消費するので注意。毎回のメッセージに注入されることを考えると、**本当に必要な情報だけ**に絞るのがポイントだよ。

## まとめ

Claude Code に時間感覚を与える方法、思ったより簡単だったでしょ？😊

- `UserPromptSubmit` フックで毎回のメッセージに現在時刻を注入
- 実装はたった **3行のシェルスクリプト**
- 時間の見積もり精度が劇的に改善する

AI にとって「時間」は意外と盲点で、でも一度与えると **できることが一気に広がる**。Claude Code の Hooks はまだまだ活用の余地がある機能だから、ぜひ自分だけの便利フックを作ってみてね！
